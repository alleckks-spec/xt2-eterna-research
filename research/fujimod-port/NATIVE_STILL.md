It initializes the actual global native profile with its constructor, supplies data-class enable bytes at6,7,0x1a,0x1d,0x2b,0x2c,0x51, and a zero-valued0x70-byte settings record at the actual caller's settings address. The native routine performs its own selector/setter calls, obtains context identity through the qualified mapper, calls its actual consumers and returns through the existing ABI wrapper. The diagnostic hash of a surrounding supplied output region is not a proved whole-buffer layout or image artifact. Checks assert numeric group results, native slots/tags, entry/return and guard release.

## Still open

This is a bounded native function check with supplied inputs. It does not establish the scheduler invoking the real capture caller, sensor acquisition, exposure-time recipe snapshots, all indirect/native copy ownership, mounted FAT/loading in the common artifact, teardown/cache coherence, encoder execution, a JPEG image, full startup or physical camera behavior. Prior controlled interleavings were central-API tests, not physical concurrent execution of this still body.

Next concrete gap: connect the existing file-loader/native open-read-close boundary to this same ordinary artifact and selected processing chain; then qualify the remaining actual producer/startup/lifetime path. Reuse existing tools and inputs rather than expanding the emulator.
