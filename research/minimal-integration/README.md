## Reproducing locally

These files are original harness sources, not a standalone public build or a
redistributable firmware package. Supply the private/local research workspace,
its extracted X-T2 4.41 and X-H1 2.15 inputs, pinned stock/base/candidate SD
images, existing reports needed by imported helpers, Python capstone, pyelftools,
and the project-compatible Unicorn TCI runtime. Build tooling also needs the
locally configured clang/LLD toolchains. Inputs are not obtained or downloaded
by these scripts. Run from that workspace; do not copy its vendor material here.

The lifetime audit is independently readable with the included original
`firmware_analysis.py`, capstone and locally supplied extracted metadata/image.
`--execute` additionally requires Unicorn. The slot assay depends on the existing
research helpers below; they are not all included in this release. Preserve
those helpers' fixture limitations. No standalone reproducibility is claimed.

The slot runner rejects any incomplete phase or mismatched getter/slot value,
pins its imported local sources before/after, and watches patch-region CPU
writes during the assay. It preserves earlier common research reports by
isolating new preparation outputs. Native code and tables are read only from
locally supplied inputs; generated reports can contain private input details
and should not be uploaded automatically.
